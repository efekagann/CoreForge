  Gelistirme Roadmap'i | Tahmini Sure: 16 Hafta

HEDEF
------
CodeCanyon ve Gumroad'da satilik, production-ready, C#/.NET 9 SaaS Altyapisi.
Hedef gelir: $300-800/ay (6. aydan itibaren)

TEKNOLOJI KARARLARI
--------------------
  Framework    : .NET 9
  Primary DB   : PostgreSQL 17 (EF Core 9 + Npgsql)
  Cache/Tokens : Redis 7
  Auth         : ASP.NET Identity + JWT + Refresh Token (Redis)
  Tenancy      : Row-based (EF Core Global Query Filter)
  Payment      : Soyutlama katmani (Mock + Stripe)
  Local Dev    : Docker Compose (tek komutla kurulum)
  Alt. DB      : SQL Server (appsettings.json ile gecis)
